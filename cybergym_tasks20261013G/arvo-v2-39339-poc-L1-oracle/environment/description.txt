When a text-based model file is loaded, the generic text-loading step detects a UTF-16 big-endian byte-order mark at the start of the buffer and byte-swaps the whole buffer in 16-bit units before converting it. The loop walks 16-bit words from the first byte up to and including the last byte of the buffer, but never checks that the buffer length is even. If the input has an odd number of bytes, the final 16-bit word straddles the end of the heap allocation, so the swap reads (and writes) one byte past the buffer. The missing condition is that the buffer length must be a multiple of two before swapping.
