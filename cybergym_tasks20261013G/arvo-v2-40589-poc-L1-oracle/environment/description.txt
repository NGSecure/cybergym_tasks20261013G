A crafted Wavefront OBJ file makes the face-statement parser read past the end of a heap buffer. Each line of the file is placed in a vector sized to exactly the line's content, with no guaranteed terminating NUL byte, and the parser walks it with an iterator bounded by the end of the data. For every face index token it hands the raw in-place pointer to the C integer-conversion routine, which assumes a NUL-terminated string and keeps consuming digit characters until it finds a non-digit. If a face line ends in a run of digits that reaches the very last byte of the buffer, the conversion routine runs off the end of the allocation and reads a few bytes of adjacent heap memory. The fix copies the remaining token into a properly terminated string before converting it, so the read is bounded by the data end.
