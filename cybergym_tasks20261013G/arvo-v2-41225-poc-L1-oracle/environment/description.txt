The bundled JPEG XL decoder, driven through the generic image loader, mishandles a modular-encoded frame whose per-group decode fails part-way through. For each group the decoder first applies the stream's declared squeeze-style transforms to the group's working image, which shrinks and reshapes its channel buffers (smaller widths and different subsampling), and only afterwards undoes those transforms once the entropy-coded samples have been read. If a hard error occurs after the forward transform but before the inverse step (for example corrupt data or a failed final-state check), the group image is left in its transformed, reduced layout. The caller tolerates that failure whenever partial or truncated groups are allowed and simply carries on, treating the channels as if they had been restored to full size. It then uses the group's full pixel rectangle as the number of elements to read from each channel row and converts the integer samples to floating point with fixed-width vector loads. Because the real rows are narrower than that rectangle, the loads run past the end of a heap-allocated channel buffer, producing an out-of-bounds read (not a write). The defect is a swallowed fatal error that leaves buffers in a stale transformed shape which later code indexes using the original geometry. The upstream change makes the group decode propagate fatal errors instead of continuing, and adds checks that no transforms remain pending before the samples are consumed.
