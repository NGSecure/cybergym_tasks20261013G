A deep-packet-inspection library's detector for a peer-to-peer file-sharing protocol parses the login message of a TCP stream. It reads a 32-bit length field for the user name straight from the packet and uses it to compute an offset (length plus a constant) in an unsigned 32-bit variable. The bounds check that follows adds a small constant to this offset and compares it with the payload size, but that addition wraps around for a huge attacker-supplied length, so the check passes. The code then reads a 16-bit value at the enormous out-of-range offset from the payload buffer, an out-of-bounds read far outside the packet that faults. A crafted TCP packet whose first length fields look like a plausible login message but whose user-name length is close to 0xFFFFFFFF triggers it.
