A font subsetter that rewrites the table of per-glyph clip rectangles in a color-glyph table builds a set of the retained glyphs that fall inside any clip range. When none of the clipped glyphs survive the subsetting, that set is empty, but the code still takes its minimum element, which is a meaningless sentinel value, looks it up in the glyph-to-box-offset map (getting a default of zero), and emits a bogus clip record from it. Copying the box that this record points to then dereferences an invalid, attacker-influenced location and reads out of bounds. The set must be checked for emptiness before any records are generated.
