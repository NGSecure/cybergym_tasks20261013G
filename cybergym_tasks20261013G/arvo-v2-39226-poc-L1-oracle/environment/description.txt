A bug in a public-suffix-list loader's internationalized-domain conversion causes a stack buffer overflow write of one byte. When a dotted domain made of many non-ASCII labels is converted label by label to its ASCII-compatible encoding into a fixed-size output buffer, the space handed to the encoder for each label accounts for the terminator but not for the label separator that is appended right after it. A label that nearly fills the buffer therefore leaves no room for the separator plus the NUL written behind it, so the terminating NUL lands one byte past the end of the stack buffer. Only labels followed by another label (a dot) trigger this.
