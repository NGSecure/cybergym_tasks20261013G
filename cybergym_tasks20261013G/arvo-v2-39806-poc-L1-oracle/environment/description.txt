A big-integer routine that reduces a value modulo a power of two first copies the operand into the result, then, for a negative operand, tries to enlarge the result's digit array to hold the full modulus width and negates the digits. The return status of that enlargement is ignored. When the allocation fails (or otherwise does not enlarge the array), the result keeps its smaller digit array, yet the negation loop still writes digits up to the computed modulus width, so it stores past the end of the heap buffer. This is reachable through a right shift on a negative number by a large bit count, where the shift count exceeds the digits the result currently holds.
