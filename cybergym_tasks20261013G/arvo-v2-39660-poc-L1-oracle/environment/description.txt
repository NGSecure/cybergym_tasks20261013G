A generic struct decoder used by a DNS record parser supports structs prefixed by a two-byte big-endian length field. It reads both bytes of that length prefix without first confirming that at least two bytes remain in the input. When a record is truncated so that only one byte is left where the length prefix should be, the second prefix byte is read from just past the end of the heap buffer, causing a one-byte heap out-of-bounds read. The resulting garbage length is only validated after it has already been read.
