Apache Arrow's C++ IPC file reader accepts a record batch containing a 32-bit time-of-day column nested inside a union, and the batch is then rendered to text for display. Time-of-day values are stored as raw integers in the column's declared unit and are not validated to lie within a single day. The text formatter converts the raw count into a duration and splits it into hours, minutes and seconds, assuming the value is non-negative and below one day. A crafted file with a negative or oversized time value makes the derived hour, minute or second component fall outside 0..99, and the two-digit helper uses that component as an index into a fixed 100-entry lookup table of digit pairs. The read therefore lands before or beyond the table in static memory, causing a global-buffer over-read. The formatter never checks that the value is a valid time of day before decomposing it.
