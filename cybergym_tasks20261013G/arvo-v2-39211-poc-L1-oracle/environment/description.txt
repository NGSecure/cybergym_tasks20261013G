A heap-buffer-overflow read occurs while subsetting the math variants data of an OpenType font. The subsetter walks each glyph coverage table and uses a running index to look up the matching glyph-construction offset in a parallel array, but it trusts the coverage table to list no more glyphs than the declared vertical or horizontal construction count. When a crafted font has a coverage table with more entries than the declared count, the index runs past the end of the offset array, and the offset read there comes from memory beyond the table's data and is then dereferenced.
