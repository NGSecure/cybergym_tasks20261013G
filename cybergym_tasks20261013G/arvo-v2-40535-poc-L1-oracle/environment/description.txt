A crafted text-variant Model 3D file makes the importer's string-sanitizing helper write one byte past the end of a small heap allocation. The helper works in two passes over the same source text: a first pass measures how long the cleaned string will be (it stops at the first carriage return or newline, and is capped at 256 characters) and allocates exactly that many bytes plus a terminator; a second pass then copies the characters into the new buffer, but it follows different stopping rules, so it silently skips a carriage return and keeps going on the same line instead of stopping where the measuring pass stopped, and it has no limit tied to the allocated size. When a header field such as the model name contains a carriage return in the middle, the copy produces more characters than were measured and overruns the buffer, writing past its end.
