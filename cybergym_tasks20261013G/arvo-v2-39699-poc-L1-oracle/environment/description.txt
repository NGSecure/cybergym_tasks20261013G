A TACACS+ packet decoder turns each length-delimited argument string into an attribute by running it through the generic text-to-value parser, even when the attribute is of an octets type, which makes the parser interpret the bytes as hexadecimal text. The hex digit validator indexes a 255-entry lookup table by the raw byte value, so a byte of 0xFF reads one element past the end of that static table. The argument bytes come straight from the packet, so an attacker-supplied 0xFF in such an argument triggers a one-byte global out-of-bounds read. The decoder should copy octets and string arguments verbatim instead of parsing them as text.
