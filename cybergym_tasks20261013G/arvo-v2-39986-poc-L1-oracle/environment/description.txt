The hexadecimal-text decoding helpers use a 255-entry static lookup table to classify and convert characters, but the table is indexed by an unsigned byte that can take 256 values. Passing text containing the byte 0xFF to the generic string-to-value conversion for an octets value makes the hex digit check read one element past the end of the table, causing a one-byte global out-of-bounds read. The root defect is the off-by-one table dimension (255 instead of 256) shared by the encode and decode alphabets and their declarations.
