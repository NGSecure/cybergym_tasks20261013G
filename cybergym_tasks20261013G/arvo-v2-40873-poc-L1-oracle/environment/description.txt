A crafted 3D GameStudio heightmap (HMP) file makes the importer crash with a wild out-of-bounds read while it handles an embedded skin texture. For the skin type that carries an embedded DDS image, the texture size is read as a 32-bit width straight from the skin header in the file, and the code allocates a buffer of that size and copies that many bytes from the current position in the input. Nothing verifies that the claimed width actually fits in the bytes remaining in the input buffer, so a file whose declared width is larger than the data that follows makes the copy read far beyond the end of the input allocation, ending in a segmentation fault. The fix adds a range check that the current position plus the declared width stays inside the input before the copy.
