mruby's built-in Class#new is implemented as a small hand-assembled bytecode routine that allocates the object and then copies the positional-argument array, the keyword hash and the block into scratch registers before calling initialize. Those copies target registers numbered well above the register count the routine declares for itself (it declares six registers but stores into the eighth). The VM only guarantees stack space for the declared register count, so when the call frame happens to end exactly at the end of the heap-allocated VM value stack, the register-move instruction that stores the argument array writes one 8-byte value just past the allocation. The condition is closed by rewriting the routine to keep its scratch data in lower registers, packing arguments directly below the call target and declaring a register count that covers every register it touches.
