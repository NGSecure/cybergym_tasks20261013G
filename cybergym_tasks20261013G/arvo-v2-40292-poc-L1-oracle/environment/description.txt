This crash is produced by php-src's tracing-JIT fuzz harness (ASan build), and it happens in the profiling phase that records a hot execution path, before any native code is generated. A function with a variadic parameter is called and becomes hot, so recording starts there, continues across its return into the calling top-level code, and then follows a `new` into a constructor. The constructor appends to a static property that is not declared, with the class designated by a `$this::` expression, so the engine throws an Error at that fetch. When the recorder examines the operands of that instruction it takes the slot holding the class expression and treats its contents as an object value, reading the object's class pointer from it; the slot does not hold a valid object at that point, so the dereference lands on a wild high address (SEGV read).
