A heap buffer over-read occurs in the colour-space conversion from planar YCbCr to interleaved RGB for 8-bit images that also carry an alpha plane. After converting the colour samples, the code copies the alpha plane row by row using a byte count of twice the image width, as if every sample were 16 bits wide. For 8-bit data each alpha sample is only one byte, so every row copy reads twice as many bytes as the row holds. On the last row this runs past the end of the alpha plane's heap allocation. The copy length should depend on the sample size (width for 8-bit, twice the width only for high-bit-depth data).
